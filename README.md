# 🐍 SnakeAI

SnakeAI is a Snake game I developed in C++ while learning and improving my programming skills.

I wanted to take the classic Snake game and make my own version of it, while practicing game logic, object-oriented programming and working with multiple classes in C++.

The project also includes an AI mode, where the snake can play automatically.

## 🎮 What the game includes

- Classic Snake gameplay
- AI gameplay mode
- Score and high-score system
- Custom menu and graphics
- Food spawning
- Collision detection
- Restart and navigation controls

## 🛠️ Built with

- C++
- Visual Studio
- Object-Oriented Programming (OOP)

## 📁 Code structure

I separated the main parts of the game into different classes to keep the code easier to understand and maintain.

- `Snake.cpp / Snake.h` – snake movement and behavior
- `Food.cpp / Food.h` – food spawning
- `Game.cpp / Game.h` – main game logic
- `main.cpp` – starting point of the application
- `assets` – images and graphical resources used by the game

## 💡 What I learned

While working on this project, I practiced C++ and OOP concepts and learned more about organizing a larger project into multiple files and classes.

I also worked with game states, collision detection, scoring and basic AI behavior.

## 🚀 How to run it

1. Download or clone the repository.
2. Open `SnakeAI.slnx` in Visual Studio.
3. Build the project.
4. Run the game.
